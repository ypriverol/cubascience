# Cuban scientific output (bibliometrics)

Interactive companion to:

> Perez-Riverol, Y. (2020). *Trends in Cuban research output: publications and patents.*  
> [arXiv:2007.09638](https://arxiv.org/abs/2007.09638)

## Contents

- `ciencia.ipynb` — Jupyter analysis (publications, citations, patents)
- `data/` — CSV/XLS inputs used by the notebook
- `images/` — static figures
- `analysis.py` — helper analysis code

## Run locally

```bash
pip install -r requirements.txt
jupyter notebook ciencia.ipynb
```

Rendered on GitHub Pages: [`/science/`](https://ypriverol.github.io/cubascience/science/).
